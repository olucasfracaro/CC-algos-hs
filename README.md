## 🚀 Sobre o Projeto

O **CC-algos-hs** é um projeto focado na implementação de algoritmos de correção e ajuste de cores com o objetivo de tornar imagens e conteúdos visuais mais acessíveis para pessoas com daltonismo (principalmente com a **tricromacia anômala**). 

Tudo isso construído utilizando a elegância, tipagem forte e pureza funcional do **Haskell**.

---

## 🛠️ Tecnologias Utilizadas

*   [Haskell](https://haskell.org) - Linguagem principal do projeto.
*   Ferramentas do ecossistema Haskell (GHC e Cabal).

---

## 📦 Como Executar

Certifique-se de ter o [GHC](https://www.haskell.org/ghc/) e o gerenciador de pacotes `cabal` instalado em sua máquina.

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/olucasfracaro/CC-algos-hs.git
   cd CC-algos-hs
   ```
2. **Compile o projeto:**
    ```bash
    cabal build
    ```
3. **Execute:**
    ```bash
    ./Main
    ```
    ou, para executar diretamente:
    ```bash
    cabal run ccalgos
    ```
